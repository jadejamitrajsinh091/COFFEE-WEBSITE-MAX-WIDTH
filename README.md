# ☕ COFFEE SOLUTIONS – Modern Coffee Shop Website

A beautifully crafted, modern and responsive **Coffee Shop Website** created using **HTML + CSS**.  
This site includes featured coffee categories, milkshake items, blogs, and a sleek footer — perfect for café websites or frontend portfolio projects.

## ✨ Features

### 🏠 Header + Navigation  
- Brand title  
- Menu options (Home, Menu, Blog, Media, Contact)  
- Clean and centered layout

### 🎯 Hero Banner  
- High-quality banner image  
- “Freshly Roasted Coffee” title  
- CTA **Shop Now** button  

### 🔥 Top Categories  
- 3 featured coffee categories  
- Beautiful card-style design  
- Hover-ready button  

### 🥤 Milkshake Section  
- 3 premium shakes  
- Prices displayed  
- Attractive Buy Now buttons  

### 📰 Blog Section  
- 3 blog posts with modern layout  
- Large images + short descriptions  

### 🦶 Footer Section  
- Multiple info columns  
- Social media icons  
- Mobile responsive footer grid
